# 날벌레 출현율 GRU · 엄물포

**AI 환경 데이터 기반 기상 반응형 친환경 날벌레 유인 시스템**
대전대신고등학교 STEMINUS · 2026 AI동행 피지컬AI

최근 기온·습도·강우·조도·시각의 흐름을 GRU(Gated Recurrent Unit)로 분석해 날벌레 출현율(0~100%)을 예측하고,
395nm UV-A LED를 고출력·저출력·소등 3단계로 제어해 날벌레를 보행로 밖으로 유도합니다.

## 작동 흐름 (인지 → 판단 → 행동)
1. **인지**: 아두이노 나노가 온습도·강우·조도 센서와 RTC 시각을 노트북으로 전송
2. **판단**: 비가 오거나 19:00~23:59 밖이면 소등. 나머지는 GRU가 최근 24시간 흐름으로 출현율 계산
3. **행동**: 출현율 40% 이상 고출력, 10~40% 저출력, 10% 미만 소등. 비가 감지되면 아두이노가 먼저 소등

## 파일
| 파일 | 내용 |
|---|---|
| `bug_lure.ino` | 아두이노: 센서 전송, 강우 안전 규칙, LED 출력 |
| `run_device.py` | 노트북: 1분 평균 → GRU 출현율 → 3단계 결정 → 아두이노 전송 |
| `train_gru.py` | GRU 모델 학습 (TensorFlow/Keras), RMSE·R²·r 출력 |
| `virtual_data.csv` | 문헌 기반 **가상** 데이터 (실측 아님, 5~9월 × 2시즌) |
| `index.html` | 직접 돌려보는 GRU 데모 페이지 |

## 실행
```
pip install tensorflow numpy pandas pyserial
python train_gru.py      # gru_bug.keras 생성
python run_device.py     # 아두이노 연결 후 실행 (PORT 수정)
```
Arduino 라이브러리: RTClib, DHT sensor library

## 검증 결과 (가상 데이터, 1년차 학습 → 2년차 평가)
| 방법 | RMSE |
|---|---|
| 조건문 추정 | 0.138 |
| 다중 선형 회귀 (R² 0.65) | 0.107 |
| 기억 없는 신경망 (R² 0.80) | 0.081 |
| **GRU (R² 0.93, r 0.96)** | **0.048** |

LED 가동 시간 693 → 387시간 (−44%), 날벌레 활동 포착률 87.0% → 82.4%

> 학습·검증 데이터는 논문 경향으로 만든 가상 데이터입니다. 실제 성능은 현장 트랩 개체 수로 다시 학습해 확인할 예정입니다.
